# 潛在客戶跟進技能

負責把一次接觸，變成得體、能推進的跟進訊息與節奏。

## 流程
1. **確認脈絡**（缺才問）：客戶是誰/階段（新詢價/報價後/沉默）、上次互動、你想達成的下一步、語氣（正式/親切）。
2. **產出**：
   ```
   ## 跟進訊息 × 2（不同語氣）
   ## 建議跟進節奏（D+1 / D+3 / D+7 各一句要點）
   ## 下一步 CTA
   ```
3. **收尾**：問要不要把此客戶的重點記進本資料夾 MEMORY.md（由使用者觸發）。

## 規範
- 不對客戶做未經確認的承諾（價格、交期、折扣）。
- 語氣專業、簡潔，尊重對方時間。

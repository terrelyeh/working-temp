# 行銷週報技能

負責把分散的成效數據，整理成一致格式、可讀的週報。

## 流程
1. **確認範圍**（缺才問）：期間、涵蓋通路（社群/廣告/EDM/官網）、主要 KPI、對比基準（上週/目標）。
2. **取得數據**：
   - **若已連接數據工具**（如廣告/分析 MCP 連接器）：用它抓真實數字，標註期間與來源。
   - **若無**：請使用者提供數字，或用其 MEMORY.md / 檔案裡既有的記錄；**絕不編造成效數字**。
3. **產出固定格式週報**：
   ```
   # 行銷週報 [期間]
   ## 一句話總結
   ## 關鍵指標（本期 vs 上期/目標，含 % 變化）
   ## 各通路重點
   ## 有效與無效（各 2～3 點）
   ## 下週行動
   ```
4. **收尾**：問要不要存成該資料夾檔案，或把「下週行動」記進 MEMORY.md。

## 規範
- 只呈現真實或使用者提供的數字；任何估計明確標示。
- 保持格式一致，方便跨週比較。

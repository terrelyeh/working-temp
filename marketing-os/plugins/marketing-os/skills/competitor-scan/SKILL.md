# 競品與市場掃描技能

負責把零散的競品資訊，整理成可決策的情報。

## 流程
1. **確認範圍**（缺才問）：要分析哪些對手、比較哪些面向（定位/定價/通路/訊息/活動）、目的（找機會點 or 防守）。
2. **優先抓真實資料**：
   - **若 Firecrawl 連接器可用**（本外掛已打包 firecrawl MCP）：用它實際爬取對手的官網、產品頁、落地頁或活動頁，取得**當前真實內容**（標語、定價、主打賣點、近期活動）。每筆都標註**來源網址與擷取時間**。
   - 若使用者給了特定網址，直接用 Firecrawl 抓那幾頁。
   - **若 Firecrawl 不可用**（未設定 `FIRECRAWL_API_KEY` 或未連接）：明說「以下為依既有知識推估、非即時查證」，並建議使用者設定連接器以取得最新資料。**絕不把推估講成即時事實。**
3. **產出比較表 + 洞察**：
   ```
   ## 競品比較表
   | 對手 | 定位 | 定價策略 | 主打通路 | 近期活動/訊息 |
   ## 機會點（我們可切入的空隙）
   ## 威脅/需防守處
   ## 建議行動（3 條，具體可執行）
   ```
4. **收尾**：問要不要把洞察轉成一份活動企劃（交棒 campaign-brief）。

## 規範
- 嚴格區分「查證到的事實」與「推估」，推估要標明。
- 不捏造對手的數字、財務或內部資訊。

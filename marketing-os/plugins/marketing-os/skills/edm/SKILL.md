# 電子報 / EDM 技能

負責產出可直接發送的 email 行銷文案。

## 流程
1. **確認要素**（缺才問）：目的（推廣/通知/再行銷）、主打內容、目標受眾、主要 CTA、品牌活動或優惠。
2. **產出固定結構**：
   ```
   ## 主旨列 × 3（各 ≤ 30 字，含 1 個帶 emoji 版本）
   ## 前置文字（preview text，≤ 50 字）
   ## 內文
   - 開頭鉤子
   - 主體（重點條列或短段落）
   - 明確 CTA 按鈕文字 × 2
   ## 補充：發送建議（時段/分眾）
   ```
3. **給 A/B 方向**：主旨列標明測試假設（好奇 vs 利益 vs 急迫）。
4. **收尾**：問要不要接著做對應的社群預告（交棒 social-post）。

## 規範
- 遵守資料夾 CLAUDE.md 的品牌 tone 與合規；不誇大、不做未證實宣稱。
- 優惠/數字以使用者提供為準，不編造。
